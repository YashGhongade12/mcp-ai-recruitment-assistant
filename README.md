# AI Recruitment Screening Assistant using MCP-Inspired Architecture

An AI-powered recruitment automation system that streamlines candidate screening by automatically parsing uploaded resumes, extracting relevant skills, evaluating candidate profiles against predefined hiring criteria, and sending automated shortlist/rejection email notifications.

Built using Flask, MySQL, PyMuPDF, SMTP email automation, and an MCP-inspired modular agent architecture to simulate enterprise AI orchestration workflows.

## Features
- Candidate application form with resume upload
- PDF resume parsing and text extraction
- Skill-based automated candidate scoring
- Shortlist / rejection decision engine
- Automated email notifications
- MySQL candidate data storage
- MCP-inspired modular architecture
- AI agent orchestration design

## Tech Stack
- Python
- Flask
- MySQL
- PyMuPDF
- SMTP
- HTML/CSS
- MCP-inspired architecture
